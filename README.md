# Customer Churn Analysis and Prediction

## Business Problem
A telecom company is losing customers. Which customers are likely to leave, and what factors drive them to leave?

## Goal
Find the main reasons for churn and recommend ways to reduce it.

## Dataset
Telco Customer Churn dataset (Kaggle), 7,043 customers, 21 columns.
